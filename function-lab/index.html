Histórico

Função afim (reta)

y = ax + b

O que cada letra faz

a
Coeficiente angular — inclinação da reta.
a > 0 sobe · a < 0 desce · a = 0 horizontal
Quanto maior |a|, mais íngreme.
b
Coeficiente linear — onde corta o eixo y (x = 0).
Aumentar b sobe a reta · diminuir desce.

Fórmulas importantes

Inclinação: a = (y₂ − y₁) / (x₂ − x₁)
Zero da função (corta o eixo x): x = −b / a
(desde que a ≠ 0)

Calculadora — digite a e b

Veja no gráfico

Truque: a = quanto y muda quando x anda 1 unidade. Se a = 2, cada +1 em x sobe y em 2.

Função quadrática (parábola)

y = ax² + bx + c

O que cada letra faz

a
Abertura
a > 0 → ∪ (mínimo) · a < 0 → ∩ (máximo)
|a| grande = estreita · |a| pequeno = aberta
b
Desloca o vértice para a esquerda/direita (junto com a).
c
Intercepto y — valor quando x = 0. Sobe ou desce a parábola.

Todas as fórmulas

Discriminante: Δ = b² − 4ac
Raízes (Bhaskara): x = (−b ± √Δ) / (2a)
  → x₁ com −    x₂ com +
Vértice: xv = −b / (2a)
          yv = −Δ / (4a)  ou  yv = f(xv)
Soma das raízes: x₁ + x₂ = −b/a
Produto das raízes: x₁ · x₂ = c/a

O que o Δ diz

Δ>0
Duas raízes reais diferentes — a parábola corta o eixo x em dois pontos (x₁ e x₂).
Δ=0
Uma raiz real (raiz dupla) — toca o eixo x em um ponto (o vértice).
Δ<0
Nenhuma raiz real — não corta o eixo x.

Calculadora — digite a, b, c

Veja no gráfico

Ordem para estudar: 1) olhe o sinal de a (abre para cima/baixo) → 2) calcule Δ → 3) ache x₁ e x₂ → 4) ache o vértice.
